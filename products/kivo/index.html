Two ways in两条入口

Agent when intent is open. Direct when control matters.意图开放时用 Agent，需要控制时直接生成。

A brief or reference can enter the Agent, which decides whether and how to generate, or the user can drive a model directly from Canvas. Both routes converge on the same server-owned media lifecycle and factual artifact contract.需求或参考素材可以交给 Agent，由它判断是否以及如何生成；用户也可以在 Canvas 直接操作模型。两条路径最终汇入同一套服务端媒体生命周期与事实产物合同。

02Direct path · explicit model workflow from Canvas直接路径 · 从 Canvas 发起明确的模型工作流

Durable execution持久执行

A job is a fact, not a request.任务是事实，不是请求。

Paid media uses an asynchronous invoke-and-poll lifecycle. Each submission is idempotent, refreshes and reconnects resume the same server-owned job, and completed artifacts replay without creating another provider request.付费媒体使用异步 Invoke-and-Poll 生命周期。每次提交均保持幂等；刷新与断线重连恢复同一个服务端任务，已完成产物只回放，不再创建新的供应商请求。

Work continues持续创作

Artifacts become editable versions on Canvas.产物进入 Canvas，成为可编辑版本。

The infinite canvas keeps dense image and video boards responsive through viewport culling, bounded media hydration, poster-only inactive video, and spatial indexing. AI edits create new versions instead of overwriting the original.无限画布通过视口裁剪、有界媒体加载、非活动视频仅渲染海报与空间索引，让密集图像／视频画板保持流畅。AI 编辑生成新版本，而不会覆盖原始产物。
