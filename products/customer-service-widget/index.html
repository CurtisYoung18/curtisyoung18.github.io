01

Integration problem集成问题

An AI agent can answer correctly and still fail delivery if its output cannot reach the customer’s existing chat surface or be continued by a human team.即便 AI Agent 回答正确，如果输出无法进入客户现有聊天界面，或无法由人工团队继续处理，交付仍然失败。

02

Interface contract接口契约

The agent emits typed widget JSON. A mapping layer validates it and converts it into LiveChat cards, quick replies, buttons, or plain text.Agent 输出带类型的 Widget JSON；映射层完成校验，并转为 LiveChat 卡片、快捷回复、按钮或普通文本。

03

Working outcome落地结果

The demo supports guided registration, promotions, recommendations, payment choices, ordinary conversation, and human transfer in one embedded surface.同一嵌入界面支持注册引导、活动推荐、游戏推荐、支付方式、普通对话与人工转接。

Message route消息链路

Keep one conversation intact across four systems.跨越四个系统，保持同一段会话完整。

The durable spine is the LiveChat chat ID. It follows each message through the webhook, agent workflow, mapping middleware, and return API so the response reaches the correct customer thread.整条链路的主干是 LiveChat chat ID。它随消息经过 Webhook、Agent Workflow、映射中间件与回传 API，确保回复进入正确的客户会话。

01 · RECEIVE LiveChat webhook接收 Webhook

Capture chat ID, thread ID, user identity, and message text from the incoming event.从入站事件中提取 chat ID、thread ID、用户身份与消息文本。

02 · DECIDE GPTBots workflowAgent 决策

The agent chooses between text, a typed interactive widget, a tool-backed answer, or escalation.Agent 在文本、带类型交互组件、工具型回答或升级处理之间做出选择。

03 · MAP Middleware contract中间件转换

Validate the payload and translate product-level widget types into LiveChat Rich Message structures.校验 Payload，并把产品级 Widget 类型转换成 LiveChat Rich Message 结构。

04 · RETURN Render or hand off渲染或转人工

Send the response to the originating chat, or preserve context for a human operator to continue.把回复发回原始会话，或保留上下文交由人工继续处理。

Typed output类型化输出

Treat rich UI as an API contract, not model prose.把富交互当作 API 契约，而不是模型自由文本。

The model selects a widget type and fills a constrained schema. The application owns parsing, validation, mapping, and rendering. This boundary makes interactive responses inspectable and gives the system a plain-text fallback when structured output is invalid.模型选择 Widget 类型并填充受限 Schema；应用负责解析、校验、映射与渲染。这个边界让交互回复可检查，并在结构化输出无效时保留普通文本回退。

Human continuity人工连续性

Escalation is part of the architecture.人工接管从一开始就是架构的一部分。

The same routing identity used for automated replies also anchors transfer. When the agent cannot complete the request, the conversation can move to an operator without opening a new thread or losing the customer’s message history.自动回复使用的同一会话身份也用于转接。当 Agent 无法完成请求时，会话可以进入人工队列，而无需创建新线程或丢失客户消息历史。
