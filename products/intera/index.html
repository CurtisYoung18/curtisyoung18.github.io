01

Problem问题

A fluent chatbot is not yet a dependable service operation. Prompt-only agents drift, hide their decisions, and break precisely when a customer needs evidence or escalation.能流畅聊天，还不等于可靠客服。只靠 Prompt 的 Agent 会漂移、隐藏决策过程，并常在客户最需要证据或升级处理时失效。

02

Approach方法

Keep one owner Agent in control, then surround it with typed Procedures, Tools, Hooks, dynamic context, trace evidence, Scenarios, and durable HumanTasks.让一个主 Agent 保持判断权，再以类型化 Procedure、Tool、Hook、动态上下文、Trace、Scenario 与持久化 HumanTask 构成控制层。

03

Result结果

A deployed operator console spanning Build, Release, Conversations, and Human Handoff, with a separate runtime service and agent-scoped operational evidence.形成覆盖 Build、Release、Conversations 与 Human Handoff 的线上运营 Console，并以独立 Runtime 服务和 Agent 级运行证据支撑日常交付。

Runtime demonstrationsRuntime 演示

Reasoning you can inspect.看得见的推理与执行。

Two synthetic demonstrations expose the system beneath the reply: evidence gathering, dynamic context, Tool and Hook decisions, structured input, and human transfer.两支合成演示把回复背后的系统展开：证据收集、动态上下文、Tool 与 Hook 决策、结构化补充信息和人工转接。

Product boundary产品边界

A control plane, not another chatbot.不是另一个聊天机器人，而是控制平面。

Intera keeps the Agent as the single owner of the customer turn while the surrounding platform makes configuration, execution, release, and evidence explicit. The Console is organized around Build and Operate; the runtime remains a separate service boundary.Intera 让主 Agent 对客户回合保持单一所有权，同时由外围平台显式管理配置、执行、发布与证据。Console 围绕 Build 与 Operate 组织，Runtime 则保持独立服务边界。

Context engineering上下文工程

Keep the core stable. Let the tail move.稳定核心，让 Tail 随运行变化。

The model receives a cache-friendly prefix for identity, service boundaries, the active Procedure, and available Tools and Hooks. Only the ProcedureRun tail changes between turns: current step, facts, blockers, evidence, and the next expected action.模型收到适合缓存的前缀，包含身份、服务边界、当前 Procedure，以及可用 Tool 与 Hook。每轮只替换 ProcedureRun Tail：当前步骤、事实、阻塞项、证据与下一步行动。

Operational truth运行事实

Evidence before confidence.先有证据，再谈信心。

A useful AgentOps system must explain more than the final answer. Intera records the runtime path, keeps customer-visible transcripts separate from privileged debug evidence, validates behavior with repeatable Scenarios, and turns unresolved work into a durable HumanTask.有用的 AgentOps 系统不能只展示最终回答。Intera 记录 Runtime 路径，将客户可见对话与高权限 Debug 证据分开，以可重复 Scenario 验证行为，并把未解决工作变成持久化 HumanTask。

03Review typed draft changes and rollback paths审查类型化草稿变更与回滚路径
04Hand unresolved work to a human with context intact保留上下文，把未解决工作交给人工
