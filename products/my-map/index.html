01

Problem问题

Conventional map tools expect structured inputs. Real travel requests arrive as incomplete sentences, preferences, and changing constraints.传统地图工具依赖结构化输入，而真实出行请求通常是残缺句子、偏好与不断变化的约束。

02

Approach方法

Use an AI interaction layer to interpret intent, then call deterministic map services for geocoding, routing, and POI search.由 AI 交互层理解意图，再调用确定性的地图服务完成地理编码、路径规划与 POI 搜索。

03

Result结果

One conversation produces an annotated route with distance, time, toll estimates, waypoints, and useful stops along the way.一次对话即可生成带距离、时间、过路费、途经点与沿途服务推荐的标注路线。

Intent first从意图开始

Make the input human.让输入保持自然。

A user can ask, “From Shenzhen Nanshan Science Park to Longhua Dalang, via Bao'an Shajing,” without learning a form or breaking the request into fields. The assistant extracts origin, destination, waypoints, and service preferences before route construction.用户可以直接说“从深圳南山科技园到龙华大浪，途经宝安沙井”，无需学习表单或拆分字段。助手会先提取起点、终点、途经点与服务偏好，再开始规划。

01Interpret places and constraints解析地点与约束
02Build and visualize the route构建并可视化路线
03Enrich the journey with POIs用 POI 丰富沿途体验

Engineering boundary工程边界

Let models interpret. Let services calculate.让模型理解，让服务计算。

The model handles language and intent. AMap services handle route geometry, duration, distance, toll estimates, and search results. MapLibre GL owns the visual representation. Keeping these responsibilities explicit makes the system easier to inspect and evolve.模型负责语言与意图，高德服务负责路线几何、时长、距离、过路费估算与搜索结果，MapLibre GL 负责可视化。明确职责边界，让系统更容易检查与演进。
